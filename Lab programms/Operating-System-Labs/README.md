# Operating-System-

## Lab Experiments

| Folder | Experiment |
|--------|------------|
| [Lab-01](Lab-01) | Create a new process by invoking the appropriate system call. Get the process identifier of the currently running process and its respective parent using system calls and display the same using a C program. |
| [Lab-02](Lab-02) | Identify the system calls to copy the content of one file to another and illustrate the same using a C program. |
| [Lab-03](Lab-03) | Design a CPU scheduling program with C using First Come First Served technique with the following considerations: (a) All processes are activated at time 0. (b) Assume that no process waits on I/O devices. |
| [Lab-04](Lab-04) | Construct a scheduling program with C that selects the waiting process with the smallest execution time to execute next. |
| [Lab-05](Lab-05) | Construct a scheduling program with C that selects the waiting process with the highest priority to execute next. |
| [Lab-06](Lab-06) | Construct a C program to implement preemptive priority scheduling algorithm. |
| [Lab-07](Lab-07) | Construct a C program to implement a non-preemptive SJF algorithm. |
| [Lab-08](Lab-08) | Construct a C program to simulate Round Robin scheduling algorithm with C. |
| [Lab-09](Lab-09) | Illustrate the concept of inter-process communication using shared memory with a C program. |
| [Lab-10](Lab-10) | Illustrate the concept of inter-process communication using message queue with a C program. |
